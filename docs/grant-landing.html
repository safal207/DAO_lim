Explainable routing for AI infrastructure.

DAO_lim is the routing layer of the Liminal Stack: an open-source reverse proxy built for AI backends where latency, failure, and semantic intent all matter.

Review stack demo Open grant materials

Why this layer matters

ProblemGeneric proxies do not explain why a request went to one AI backend instead of another.
ConsequenceTeams get avoidable latency spikes, poor failover, and routing behavior that is hard to justify.
ContributionDAO_lim makes backend selection explicit, inspectable, and measurable.

The grant case

Open infra

DAO_lim is reusable as a standalone routing and control layer, not tied to one downstream app.

Trust and visibility

The value is not only routing traffic. The value is being able to inspect and explain the choice.

Stack fit

DAO_lim complements storage and runtime layers by making the entry point of the stack accountable too.

What reviewers should remember

  • AI traffic behaves differently from generic HTTP traffic.
  • Opaque routing creates operational and trust debt.
  • DAO_lim exists to make backend choice explicit, inspectable, and open.

Best next milestone

The strongest next step is real end-to-end routing evidence against live backends, including measured failover behavior and reviewer-readable decision output.
