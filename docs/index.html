Project Landing

Explainable routing for AI infrastructure.

DAO_lim is an open-source routing layer for AI backends where latency, failure, and semantic intent all matter. It exists to make backend choice explicit, inspectable, and measurable.

Review stack demo View NLnet overlay

Why it exists

ProblemGeneric proxies do not explain why one model backend or worker got the request.
ConsequenceTeams inherit latency spikes, weak failover, and opaque routing behavior.
ContributionDAO_lim turns routing from hidden glue into a reviewable infrastructure decision layer.

Why it matters

Open infra

Reusable as a standalone routing and control layer, not tied to one downstream application.

Trust and visibility

The value is not only routing traffic. The value is being able to inspect and justify the choice.

Stack fit

DAO_lim complements storage and runtime layers by making the entry point accountable too.

What to remember

  • AI traffic behaves differently from generic HTTP traffic.
  • Opaque routing creates operational and trust debt.
  • DAO_lim exists to make backend choice explicit, inspectable, and open.
